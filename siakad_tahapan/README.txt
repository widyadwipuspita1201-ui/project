PAKET LATIHAN SIAKAD - BERTAHAP

Isi:
- database.py: modul koneksi MySQL dan autentikasi (template, sesuaikan dengan database Anda)
- tahap1_login.py: latihan halaman login
- tahap2_dashboard.py: login + dashboard/sidebar
- tahap3_tabel.py: dashboard + menampilkan tabel akademik
- tahap4_crud.py: aplikasi CRUD (tambah, edit, hapus, refresh)
- tahap5_logout.py: aplikasi CRUD + logout
- tgs.py: versi final lengkap (sama fungsi dengan tahap5_logout.py)

PENTING:
1. Semua file .py harus berada di folder yang sama.
2. Sesuaikan konfigurasi MySQL di database.py.
3. Database MySQL bernama `siakad` dan tabel yang dipakai harus sudah dibuat.
4. Tahap 2-5 adalah file kumulatif agar tiap tahap dapat dijalankan sendiri.
5. Jalankan contoh: python tahap1_login.py
6. Jalankan final: python tgs.py
